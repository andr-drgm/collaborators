# USDC Bounty Marketplace MVP

## Overview

This repository contains the MVP for a USDC bounty marketplace built with Next.js, React, and Privy for authentication. The system allows users to create, claim, and solve bounties with USDC payments handled through a webhook flow.

## Features

- **Privy Authentication**: Secure user authentication and wallet management
- **Bounty Dashboard**: View and manage bounties with tabbed interface
- **Webhook Integration**: Automatic bounty status updates when solutions are submitted
- **USDC Payments**: USDC transfers are processed through a webhook (on-chain transfer not yet implemented)

## Prerequisites

- Node.js 20+
- PostgreSQL 15+
- Privy account (see [PRIVY_SETUP.md](./PRIVY_SETUP.md))

## Setup Instructions

1. Clone the repository:
   ```bash
   git clone https://github.com/your-org/usdc-bounty-marketplace.git
   cd usdc-bounty-marketplace
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Configure environment variables:
   ```bash
   cp .env.example .env.local
   ```
   Edit `.env.local` with your Privy and database credentials.

4. Set up the database:
   ```bash
   npx prisma migrate dev
   ```

5. Start the development server:
   ```bash
   npm run dev
   ```

## Key Components

### Authentication
- Privy integration in `src/lib/privy.ts`
- Protected routes in `src/middleware.ts`

### Bounty Management
- Dashboard with tabs in `src/app/dashboard/page.tsx`

### Webhook Flow
- Solution submission webhook in `src/app/api/webhook/route.ts`
- Updates bounty status to `SOLVED` when a solution is approved
